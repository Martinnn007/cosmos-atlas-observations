# Cosmos Atlas observation assets

Public science datasets prepared for the Cosmos Atlas browser visualization. This repository contains only processed observation assets and their metadata.

- [Terrain](v1/terrain/manifest.json) lists source products, datum, coverage, and resolution.
- [Surface imagery and shapes](v1/observed/manifest.json) credits source missions and institutions.
- [DESI Early Data Release](v1/deepsky/desi-edr.json) gives the source, distance convention, license, and required acknowledgments.
- [Pillars of Creation](v1/deepsky/pillars.json) credits the STScI shape reconstruction and identifies the illustrative volume parameters.
